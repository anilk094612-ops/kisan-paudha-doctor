# 🌾 किसान पौधा डॉक्टर AI (Kisan Paudha Doctor AI)

ग्रामीण किसानों के लिए फसल रोग, कीट, पोषण निदान, मौसम एवं मंडी भाव सहायता ऐप।

---

## 📲 GitHub से APK कैसे डाउनलोड करें (How to Download APK)

### तरीका 1: GitHub Releases से सीधा APK डाउनलोड करें (सबसे आसान तरीका)
1. अपने GitHub रिपॉजिटरी पेज के दाईं तरफ (Right Sidebar) **"Releases"** सेक्शन पर जाएं।
2. सबसे नए रिलीज (Latest Release) पर क्लिक करें।
3. **Assets** के नीचे सीधे **`KisanPaudhaDoctor-Debug.apk`** पर क्लिक करके डाउनलोड करें।
4. डाउनलोड होते ही अपने मोबाइल में खोलें और **Install** दबाएं।

---

### तरीका 2: GitHub Actions (Artifacts) से डाउनलोड करें
1. अपने GitHub रिपॉजिटरी में ऊपर **"Actions"** टैब पर क्लिक करें।
2. बायीं तरफ **"Build & Download Kisan Paudha Doctor APK & AAB"** वर्कफ़्लो चुनें।
3. सबसे ऊपर वाले सफल रन (Green Checkmark ✅) पर क्लिक करें।
4. पेज के सबसे नीचे स्क्रॉल करें, आपको **Artifacts** दिखेगा:
   * ⬇️ **`KisanPaudhaDoctor-APKs`** – इस पर क्लिक करें। यह ZIP फ़ाइल में APK डाउनलोड करेगा।
   * ⬇️ **`KisanPaudhaDoctor-AAB`** – Google Play Store पर अपलोड करने के लिए बंडल।

---

### तरीका 3: जब चाहें नया APK खुद बनाएं (Manual Trigger)
1. GitHub में **"Actions"** टैब पर जाएं।
2. **"Build & Download Kisan Paudha Doctor APK & AAB"** पर क्लिक करें।
3. दाईं ओर **"Run workflow"** बटन पर क्लिक करें और शाखा (Branch) चुनकर **"Run workflow"** दबाएं।
4. लगभग 2–3 मिनट में वर्कफ़्लो पूरा होगा और नया APK डाउनलोड के लिए तैयार हो जाएगा!

---

## 📱 मोबाइल में इंस्टॉल करने का तरीका
1. जब APK डाउनलोड हो जाए, तो फ़ोन के नोटिफिकेशन या **Downloads** फ़ोल्डर में जाकर फ़ाइल पर टैप करें।
2. यदि फ़ोन पूछे **"Install unknown apps"**, तो अपने ब्राउज़र को **"Allow from this source"** की अनुमति दें।
3. **Install** पर क्लिक करें।
4. ऐप इंस्टॉल होते ही किसान पौधा डॉक्टर AI आपके मोबाइल में उपयोग के लिए तैयार है!
